## Projects

###  AI, Agents & DevTools
- [Xeus](https://github.com/diiviikk5/Xeus) - Browser-native playground & IDE for building, testing, and deploying Solana AI agents with zero local setup (TypeScript, Next.js).
- [Tazent](https://github.com/diiviikk5/Tazent) - Sentry for browser agents: real-time crash telemetry, visual step replays, and AI failure summaries (TypeScript).
- [OpenLVM](https://github.com/diiviikk5/OpenLVM) - Agent runtime and testing harness built around a Zig core and Python operator layer.
- [Aegtion](https://github.com/diiviikk5/Aegtion) - Local-first workflow runner combining shell checks, AI prompts, browser tasks, and approval steps (JavaScript).
- [Agent-Dih](https://github.com/diiviikk5/Agent-Dih) - Personal website-testing agents that browse and judge UX like a specific user profile (JavaScript).
- [The-Smooth-Operator](https://github.com/diiviikk5/The-Smooth-Operator) - AI-powered cold outreach engine that researches leads, crafts hyper-personalized emails, and manages campaigns (Python).
- [rezops](https://github.com/diiviikk5/rezops) - Garry's Stack: Claude Code skills + fast headless browser for end-to-end AI engineering workflows (TypeScript).
- [dvkcli](https://github.com/diiviikk5/dvkcli) - Personal Pocket GPT: Local-first terminal AI assistant powered by Ollama (Go).
- [Project-SS](https://github.com/diiviikk5/Project-SS) - SarkariSaathi: Multilingual AI voice calling agent for Indian government citizen services (JavaScript).
- [but-are-you-a-human](https://github.com/diiviikk5/but-are-you-a-human) - Interactive visual testing ground and web policy simulator for AI agent access permissions (`agent-policy.json`).
- [hpot](https://github.com/diiviikk5/hpot) - AI-powered honeypot system that engages scammers via autonomous agents to extract threat intel (Python).
- [Parallel-You](https://github.com/diiviikk5/Parallel-You) - Next-generation AI chat platform with customizable AI personas (JavaScript, Vite).

- [Muks](https://github.com/diiviikk5/Muks) - Living, intelligent desktop shell for Windows 11 with biome transitions (Rust).
- [Muks-TUI](https://github.com/diiviikk5/Muks-TUI) - Windows desktop customization control plane orchestrating Lively Wallpaper, Rainmeter, YASB, and Komorebi (Rust).
- [Boltv1](https://github.com/diiviikk5/Boltv1) - Windows-first, zero-bloat CLI game launcher (Rust).
- [gloader](https://github.com/diiviikk5/gloader) - A generic attempt towards a fast, custom game launcher.
- [ricedl](https://github.com/diiviikk5/ricedl) - Fast CLI file downloader and archive extractor with a BubbleTea TUI (Go).
- [Comio](https://github.com/diiviikk5/Comio) - Desktop comic reader integrated with the Internet Archive library (Python).
